# analise-preditiva-violencia-mg
Análise Preditiva e Espacial da Violência Doméstica (MG): Projeto ponta-a-ponta de Ciência de Dados focado na extração de insights estratégicos para tomada de decisão em segurança pública. Envolve engenharia de dados (ETL com SQLite), análise exploratória multivariada (Pandas/Matplotlib) e modelagem preditiva (KNN, Regressão Logística). O grande diferencial técnico é a implementação matemática from scratch da Regressão Ridge e OLS via Numpy, provando domínio fundamental sobre os algoritmos de Machine Learning, aliados a uma forte capacidade analítica de traduzir números em contexto de gestão.
